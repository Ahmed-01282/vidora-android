# Vidora Android Gradle

Local yt-dlp Android test application with a test AdMob banner. The app does not use an extraction API. Internet is still required to access the source platform.

Build with:

```bash
./gradlew :app:assembleDebug
```

The AdMob IDs in this starter project are Google's official test IDs. Replace them only after creating your own AdMob app and ad units.
